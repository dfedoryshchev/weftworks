# spec: one line, what this delivers

## context
one or two lines. why this exists, what it touches.

## invariants (must hold when done)
- [ ] ...
- [ ] ...

each one must be checkable. if you can't name how you'd check it, it isn't an invariant.

## out of scope
what this deliberately does NOT change.

## verify
how each invariant is checked - test, command, or manual step.
