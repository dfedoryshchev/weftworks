# using these

these aren't a framework, they're conventions. two ways to use them:

**as claude code skills.** copy a skill folder into your project's skills setup (or point the
agent at this repo's skills dir). the agent loads the convention when it's relevant.

**as a workflow.** the spec-driven loop (workflow/spec-driven-loop.md) is the spine; the skills
are its steps. start there: write the spec, plan, execute, verify.

pick the few that fit how you already work. a convention you don't follow is worse than none,
it's just noise the agent has to ignore.
