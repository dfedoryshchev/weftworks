# a claude.md that survives long sessions

what holds up when a session runs long:

- **top of file: the one job.** what this project is, in two lines. the agent re-reads the
  top most, so put what matters there.
- **hard rules as a short list**, not prose - the things that must never happen.
- **point to specs and skills, don't inline them.** a fat claude.md rots; links stay current.
- **keep it under a screen.** longer than that and the agent skims it like a docs site.

what rots fastest: long code samples, anything with a date in it, "current status" paragraphs.
