# agents.md notes

agents.md is the cross-tool version of a claude.md - same idea, not tied to one agent. notes
from moving between them:

- keep ONE source of truth. if both files exist, one points at the other; they don't both
  carry rules that drift apart.
- the good parts are the same everywhere: the one job at the top, hard rules as a list,
  links not inlines.
- tool-specific bits stay in the tool's own file; the shared conventions go in agents.md so
  every tool sees them.
